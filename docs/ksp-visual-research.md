# KSP visual effects and asset research — 2026-11-14

## Decision

Build original URP rocket visuals and plume effects. CKAN is a KSP mod installer, not an asset license or a Unity package source. Do not bundle Waterfall, RealPlume, or Starship Expansion Project art for commercial redistribution under the terms observed below. No URP import or runtime has been tested.

## Primary source findings

- **Waterfall Core 0.11.0:** [release](https://github.com/KSPModStewards/Waterfall/releases/tag/0.11.0), [license at tag](https://github.com/KSPModStewards/Waterfall/blob/0.11.0/LICENSE.md), [CKAN metadata](https://github.com/KSPModStewards/Waterfall/blob/master/CKAN/Waterfall.netkan). The release zip is 6,195,771 bytes. Its license says all content except separately licensed bundled mods is CC BY-NC-SA 4.0; no general MIT code exemption is stated. Treat code, shaders, meshes, textures and configurations as noncommercial/share-alike unless a specific exception is verified. ModuleManager and bundled sound collections have separate licenses. Waterfall is a KSP framework, requires ModuleManager, and needs effect configs; it is not a standalone Unity package.
- **RealPlume v13.3.2:** [release](https://github.com/KSP-RO/RealPlume/releases/tag/v13.3.2), [root asset license](https://github.com/KSP-RO/RealPlume/blob/master/GameData/RealPlume/license.txt), [CKAN metadata](https://github.com/KSP-RO/RealPlume/blob/master/RealPlume.netkan). Root states CC BY-NC-SA 4.0 and explicitly requests original artists' permission before redistribution because effects have different sources. For example, [Ferram FX](https://github.com/KSP-RO/RealPlume/blob/master/GameData/RealPlume/Ferram_FX/0license.txt) says CC BY-SA without version; [Hoojiwana FX](https://github.com/KSP-RO/RealPlume/blob/master/GameData/RealPlume/Hoojiwana_FX/0license.txt) says CC BY-SA 3.0; [Nertea FX New](https://github.com/KSP-RO/RealPlume/blob/master/GameData/RealPlume/Nertea_FX_New/License_ARR.txt) is all rights reserved; [Zorg FX](https://github.com/KSP-RO/RealPlume/blob/master/GameData/RealPlume/Zorg_FX/license.txt) is CC BY-NC-SA 4.0. Even the apparently commercial-friendly individual effects have root permission and share-alike issues: do not treat the package as permissive. CKAN specifies SmokeScreen, ModuleManager and RealPlumeConfigs dependencies and KSP 1.8–1.12.99; the GitHub latest-release endpoint returned v13.3.2, which is not a verification of latest CKAN metadata.
- **Starship Expansion Project:** [upstream README and license statement](https://github.com/Kari1407/Starship-Expansion-Project). Explicitly reserves all rights for .dds, .png, .mu artwork and StarshipExpansionProject.dll; other material is GPL, not MIT. No reuse or redistribution of those assets without express permission. The KSP model is therefore not a permissible off-the-shelf Starship solution.
- **SLS:** NASA's [SLS Block 1 page](https://science.nasa.gov/3d-resources/space-launch-system-sls-block-1/) lists a 13.09 MB STL; it is not a textured GLB, and the page inspected did not establish model-specific authorship/rights. Do not assume a logo or every third-party texture is public domain. NASA's [media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/) distinguish generally uncopyrighted NASA model data from protected insignia, third-party content and endorsement restrictions. Source verification, branding review and conversion remain necessary.

## Portability and implementation

Inspection of Waterfall's [Additive Dynamic shader](https://github.com/KSPModStewards/Waterfall/blob/0.11.0/Source/ShaderLab/Additive%20Dynamic.shader) shows a built-in pipeline surface shader, `#pragma surface`, and `SquadCore/LightingKSP.cginc`; it uses mesh deformation, scrolling texture, transparency and Fresnel-like falloff. It cannot be assumed to run in URP and is noncommercial licensed. Its KSP-specific `.mu` meshes and configuration/controller system are likewise not direct URP imports. The concepts are general, but author new assets/code rather than copying source or values.

For an original, fast prototype: make a low-poly, axially oriented plume mesh with multiple shells; use a custom URP unlit transparent additive or alpha-blended material, scrolling original procedural noise, axial fade and emissive core. Bind length, width and brightness to simulated engine-on state, throttle and ambient pressure, widening toward low pressure with smoothly clamped, explicitly artistic curves; do not imply a validated exhaust-flow model. Add a modest launch-only, ground-anchored smoke particle system, distinct from high-altitude exhaust. Disable on fuel cutoff/staging; avoid per-engine heavy lights and overdraw for booster clusters. Test depth sorting, exposure/bloom, fixed-step state handoff and packaged target performance. Use the selected downloaded Starship V3 and NASA SLS geometry, with documented source, pivots and materials, then export to Unity and visually validate; model fidelity, SpaceX/NASA branding, staging separation and flight parameters require separate verification.

Research above did not copy KSP assets. Subsequently, CKAN v1.36.4.26132 was installed and its arm64 command-line version verified in the project VM; KSP itself and its mods were not installed. The selected rocket downloads and adaptation status are tracked in model-acquisition.md.
